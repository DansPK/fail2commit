## Notes and pending evidence

- WSL Ubuntu needed `nodejs npm gcc git` (apt) for the host-side npm and the C build; without them the Linux npm e2e cannot run there.
- A Windows C toolchain was not staged; the Windows native build is a staged node script.
- Bubblewrap gives a package a private `/tmp`, so a hostile `write_outside` can succeed inside the sandbox; the test asserts the host file does not exist.
- `fail2commit setup` takes about 10 s per call; `fail2commit --approver none git push` returns git's exit status (1), not 11; npm returns 11.
- Not run: `cargo fmt`/`clippy` inside `f2c-linux-test:1` (no rustfmt there).
