# SPEC-004 — npm

FR-004 · TC-004 · Owner paths: npm resolver, staging, commit/apply and fixtures.

Support project-scoped npm ci, npm install and npm i <package> for supported npm versions and registry packages. Stage manifest, lockfile, settings and resolution in a disposable workspace. Run resolution with lifecycle scripts disabled and unsupported Git, local, URL and extension execution paths closed before delegating; handle them as unsupported instead of pass-through. Review the exact lockfile graph, source, version and integrity for direct and transitive packages, and stage verified artifacts. Pin effective registry/config and validate archive paths. Apply using reviewed inputs with network resolution disabled or otherwise proved unable to substitute artifacts. Lifecycle code routes through SPEC-007/008 only. Preserve intended manifest and lockfile updates for npm install. Cancellation leaves the original project untouched; journal staged apply/recovery where needed. Lock per project and check input fingerprint at apply time. Preserve npm lifecycle context for approved build jobs and verify a real native module. On Windows avoid sending user-controlled arguments through cmd.exe interpolation; resolve a trusted node executable and npm CLI JS entry.
