# SPEC-005 — pip

FR-005 · TC-005 · Owner paths: pip resolver, staging, verification and fixtures.

Support registry wheel installs by package name and supported requirements files, bound to the selected interpreter/platform/venv. Provide an explicit guarded interpreter entry point for python -m pip and py -m pip users. A pip shim cannot intercept arbitrary interpreter calls. Reject editable, VCS, local paths, direct URLs and untrusted index/requirements directives before resolution. Protect against transitively supplied direct references as well. Enforce a wheel-only, registry-only artifact acquisition boundary before invoking any resolver that could prepare source metadata. One acceptable design is an allowlisted wheel-only staging index with verified wheel metadata and direct references rejected before pip resolution. Never rely on a dry run alone for execution safety. Use a pip plan/report for exact resolved wheel versions, then stage and hash-check all approved artifacts. Apply offline to the target interpreter from the reviewed wheel set, with no dependency re-resolution, and reject substitutions. Report unsupported source-only dependencies. Test resolver cancellation and interrupted apply on disposable venvs.
