# Product requirements

## PRD-001

- **Links** BR-001
- **Story** As a Git user, I can push normally and review risky changes before they reach a remote.
- **Priority** Must
- **Status:** Approved

## PRD-002

- **Links** BR-002
- **Story** As a developer, I can review exact dependencies and run necessary builds under isolation.
- **Priority** Must
- **Status:** Approved

## PRD-003

- **Links** BR-003
- **Story** As a Windows or Linux user, I can install a free, lightweight guard and use it from VS Code.
- **Priority** Must
- **Status:** Approved

## PRD-004

- **Links** BR-002
- **Story** As a developer, I can see what the guard is checking while it works, and its malware data and rules stay current without waiting for a new release.
- **Priority** Must
- **Out of scope** Cancel from the progress window; an offline copy of all vulnerability advisories.
- **Status:** Draft

## PRD-005

- **Links** BR-001, BR-002
- **Story** As a developer on Linux or Windows, the guard covers every shell I use, and a hostile install script cannot get out of the sandbox.
- **Priority** Must
- **Status:** Draft
