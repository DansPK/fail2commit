## Concrete residual findings

### R4-01 — High: root capability-query quarantine is neither checked nor protected by its lifecycle entry points

**Trigger:** a QEMU capability query in `vm prepare` reaches unconfirmed containment. `verify_qemu_support` passes `Some(LIB_DIR)` to every `run_bounded` query (`vm/prepare.rs:533-547`), which retains the owned child and persists a record under `/var/lib/fail2commit-vm` (`vm/prepare.rs:830-868,1675-1699`). The next `prepare()` calls `prepare_inner`, creates that directory and immediately starts new QEMU queries without `recover_or_refuse(LIB_DIR)` (`vm/prepare.rs:111-114,135-153`). `remove()` calls `remove_inner` and recursively deletes the entire library directory without checking an in-process or durable live query record (`vm/prepare.rs:120-123,360-379`). After a restart, this can erase the only durable identity and permit more queries while the previous process remains unconfirmed. The test calls `recover_or_refuse` explicitly, so it does not cover either production entry point. **Fix:** make prepare and remove run the same fail-closed recovery/refusal check for the query quarantine before spawning or deleting; ensure a live record cannot be erased by normal removal. Add entry-point tests that leave an unconfirmed query and attempt prepare/remove, including a fresh-process recovery case.

### R4-02 — Medium: query containment can exceed the shared absolute deadline

**Trigger:** a query leader is still alive when `contain_group` starts close to or after the query deadline, such as after an unusually slow drain or process scheduling delay. `contain_group` sets `reap_deadline = deadline.max(Instant::now() + REAP_FLOOR)` with `REAP_FLOOR = 250 ms` (`vm/prepare.rs:77-80,717-749`). `run_bounded_with_grace` passes its one absolute `deadline` into this helper (`vm/prepare.rs:910,970,988,1014`), so cleanup can continue at least 250 ms beyond it. The fixture's 400 ms query accepts up to 1200 ms (`vm/prepare.rs:2512-2519`), and the 1 s near-bound test accepts 1500 ms (`vm/prepare.rs:2467-2485`); neither proves the claimed hard bound. **Fix:** reserve the reap window before the deadline and return an honest unconfirmed result at the deadline, or state and test a larger explicit outer deadline that includes the floor. Keep the same budget for `/proc` enumeration and final drain.
